# LumiLayer — Multi-Page Website

LumiLayer is a fictional digital services agency created as an educational project for Task 7 of the Synent Technologies Web Development Internship. Its tagline is **“Designing the layers of your brand.”** The sample content is placeholder content throughout.

> Educational project. LumiLayer is a fictional company.

## Project structure

```text
├── index.html
├── about.html
├── services.html
├── contact.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── images/          # Reserved for optional image assets
└── README.md
```

## Pages

- **Home (`index.html`)** — Agency introduction, service previews, reasons to choose LumiLayer, and calls to action.
- **About (`about.html`)** — Company story, mission, vision, fictional team profiles, and values.
- **Services (`services.html`)** — Six service cards and the Plan, Design, Build, and Launch process.
- **Contact (`contact.html`)** — Placeholder contact details and a front-end-only inquiry form.

## Features

- Responsive, mobile-first layouts for small screens, tablets, and desktop.
- Shared navigation with the current page highlighted and a small-screen menu button.
- Consistent colors, typography, spacing, header, and footer across pages.
- Semantic HTML, visible keyboard focus, labeled form fields, and reduced-motion support.
- Front-end form checks for required fields and valid email format, followed by an on-page success message. The form does not send or store submissions.
- CSS-built layered-squares wordmark and hero illustration; no image assets are required.

## Technologies

- HTML5
- CSS3 (custom properties, Grid, Flexbox, and media queries)
- Vanilla JavaScript
- Google Fonts: Poppins and Inter

No frameworks or CSS libraries are used.

## Run locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

For a local development server, open the folder in an editor such as Visual Studio Code and use a static-server extension. The site has no build step or package installation. Google Fonts are loaded from Google Fonts, so the chosen fonts require an internet connection; system sans-serif fonts are used as fallbacks.
